v0.45.0

November 26, 202610 added
Download for Windows installerClaudeNotch-0.45.0-windows-x64-setup.exeWindows 10 (1809+) and 11, x64. Arm runs it under emulation.
Added10 entries
  • 1/10

    ClaudeNotch on Windows: the Mac app's notch at the top centre of your screen, with Claude Code's permission prompts, questions and status, for the CLI and the VS Code extension.

  • 2/10

    Permission cards with the command or the diff: Allow, Deny, deny with a reason, Always Allow (this exact command, or every call of the tool) and Allow All.

    Enter allows, Esc denies.

  • 3/10

    Destructive commands (Remove-Item -Recurse, rd /s, iwr | iex, git push --force and more, for PowerShell, cmd and Bash) get a red card and need Windows Hello or a press and hold to allow.

  • 4/10

    Questions, several at once, with your own answer, and a small tab beside the notch for the ones you put away.

  • 5/10

    Auto-Approve with a scope, a choice for destructive commands, and a timer; “allowed 3 times” beside Always Allow; and cards that say “too late to answer here” instead of vanishing.

  • 6/10

    The open notch shows the model, effort, branch, context and cost, the running command with its clock, the task list, the permission mode and edited files, and every session when you run several.

  • 7/10

    Claude's last reply in full, a history drawer (Ctrl+Alt+H) with Resume, spend per project and every card you answered, and the plan limits with their reset times.

  • 8/10

    Send to Claude (Ctrl+Alt+N), Reply on a finished session, and drop a folder or file on the notch to start Claude there in its own Windows Terminal window.

  • 9/10

    A Windows app: per-user installer with no admin rights, Start menu, tray menu, jump list, launch at login, Ctrl+Alt+, for Settings from anywhere, and a Settings window like the Mac's with usage charts, history, sounds, skills, budgets and rules.

  • 10/10

    Pet Mode, the Mac's sounds, hidden from screen recordings by default, an update check, and an opt-in card before a session switches to a pricier model.

Install or update to v0.45.4

Install straight over an older version, no uninstall needed: the running copy is closed and started again on the new one.

Download for Windows

ClaudeNotch-0.45.4-windows-x64-setup.exe · Windows 10 (1809+) and 11, x64. Arm runs it under emulation.

  1. Open the installer. No administrator rights and no UAC prompt.
  2. On the last page leave Start ClaudeNotch ticked: it connects Claude Code to the app and starts it at the top centre of your screen.
  3. Restart any Claude Code sessions that were already open, so they pick up the hooks.

The installer is not code-signed yet, so Windows SmartScreen may warn when you open it. Signing is coming in a later release. Found a bug? Let us know.

v0.44.0

November 17, 20262 added1 changed2 fixed
Download for Linux .debclaudenotch_0.44.0_all.debUbuntu, Debian, Mint, Pop!_OSDownload for Linux tarballclaudenotch-0.44.0-linux.tar.gzFedora, Arch, openSUSE and others
Added2 entries
  • 1/2

    A Settings window.

    Right-click the notch and choose Settings, right-click ClaudeNotch in the dock or app grid, launch it again while it runs, or run claudenotch --settings. Its pages cover start at login, the greeting, sessions on hover, session updates, notifications, the Claude Code hooks (install or remove), every Always allow rule (each removable), and the version, log and Quit.

  • 2/2

    Right-click the notch for Settings and Quit, also on the app's dock icon, and claudenotch --quit quits it.

Changed1 entry
  • 1/1

    Desktop notifications for cards are off by default.

    The card is already on screen, and on Ubuntu the notification banner landed right on top of it. Turn them on in Settings, for every card or for dangerous calls only.

Fixed2 entries
  • 1/2

    Installing a new version replaces the running one.

    The package was upgraded, but the old app kept running the old code, so an update looked like it did nothing until you uninstalled. Now the app restarts itself into the new version within a few seconds, after any card you are answering, and says it was updated. Upgrading from 0.43.x restarts the running copy for you, and the tarball's install.sh replaces a running copy too.

  • 2/2

    Removing ClaudeNotch removes all of it.

    apt remove and apt purge now stop the running app and take its hooks out of your Claude Code settings, keeping your own; purge also deletes its token, rules, settings and log. Removed 0.43.x and still getting notifications? Run linux/packaging/remove-leftovers.sh from the repository as yourself, then restart open claude sessions.

v0.43.1

November 17, 20263 fixed
Download for Linux .debclaudenotch_0.43.1_all.debUbuntu, Debian, Mint, Pop!_OSDownload for Linux tarballclaudenotch-0.43.1-linux.tar.gzFedora, Arch, openSUSE and others
Fixed3 entries
  • 1/3

    The notch shows on Ubuntu.

    It was drawn at the very top of the screen, behind GNOME's top bar, so the idle pill was invisible and every card lost its first row. It now hangs just below the bar, like a notch, and sits below the top panel on KDE and XFCE too.

  • 2/3

    Starting the app has a visible result.

    It says ClaudeNotch is running for a few seconds after it starts, and launching it again while it runs makes the running app say so instead of doing nothing. Errors from an app-menu launch now show as a desktop notification and are written to ~/.cache/claudenotch/claudenotch.log, which claudenotch --status points to.

  • 3/3

    The app still starts when XWayland refuses it, falling back to native Wayland instead of quitting with no display.

v0.43.0

November 17, 20262 added
Download for Linux .debclaudenotch_0.43.0_all.debUbuntu, Debian, Mint, Pop!_OSDownload for Linux tarballclaudenotch-0.43.0-linux.tar.gzFedora, Arch, openSUSE and others
Added2 entries
  • 1/2

    ClaudeNotch runs on Linux.

    The same permission card, questions, danger warnings and secret redaction as the Mac app, in a small pill at the top centre of the screen that grows into a card when Claude needs you and into your session list when you point at it. Install the .deb with sudo apt install ./claudenotch_0.43.0_all.deb, or unpack the tarball and run its install.sh, which needs no root. Either way it starts at login and connects itself to Claude Code on first run, keeping your own hooks.

  • 2/2

    Linux-specific danger warnings.

    Commands that persist or escalate on Linux get the same second-click guard as rm -rf and sudo: pkexec, systemctl enable, and writes to autostart entries or systemd user units.

Install or update to v0.44.0

Install straight over an older version, no uninstall needed: the running copy is replaced by the new one.

Download the .deb

Ubuntu, Debian, Mint, Pop!_OS

sudo apt install ./claudenotch_0.44.0_all.deb
Download the tarball

Fedora, Arch, openSUSE and others

tar xzf claudenotch-0.44.0-linux.tar.gz
./claudenotch-0.44.0-linux/install.sh

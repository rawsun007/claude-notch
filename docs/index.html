Features

Everything Claude needs, up in the notch

ClaudeNotch mirrors the prompts Claude Code shows in your terminal, then lets you handle them without breaking focus.

Permissions in the notch

Allow, Deny, or Always-Allow a command or edit right in the notch, then your keyboard is back in the terminal. No app switching, no lost focus.

See the diff first

Edit and Write requests show a red and green diff inside the card.

Guardrails for risky commands

rm -rf, sudo, and force-push get a red warning and a press-and-hold to confirm.

Cost, context, and plan limits

Live session cost and context left, plus your 5-hour and weekly usage with reset countdowns.

See a usage limit coming

Hover a plan-limit bar and it projects when the cap arrives at your current rate, not just where you are right now.

Every session at a glance

Run Claude in five projects at once and see what each is doing, its branch, and its spend.

Every screen at once

On an external monitor? The notch renders on every display at the same time and follows your cursor between them.

Claude Code and Codex (beta)

Turn on Codex support and your OpenAI Codex sessions show up in the notch too: status, context, resume, and a task bar, each tagged so you know which is which.

Drop a folder onto the notch

Drag a folder onto the notch and Claude opens a session right there.

One settings window

Alerts, budgets, a sound per pop-up, the pet, and a usage heatmap. Open with ⌥⌘,.

Nine languages

Chinese, Spanish, Hindi, Portuguese, Japanese, German, French, Korean, and Russian. Switch instantly, no restart.

Pet Mode

A creature lives in your notch, reacts to the run, and backflips when you boop it. One click to turn off.

Why not just use the terminal?

Because the terminal is where you are not looking

Claude Code already works fine in a terminal. The problem is not the terminal, it is that answering it means being in the terminal, and you are somewhere else.

You find out it asked when you look

A permission prompt blocks the run and waits. If the terminal is behind your editor, the session is stopped and you have no idea, sometimes for minutes. The notch pops the prompt over whatever you are in.

The diff is in the other window

Approving an edit means switching, reading, switching back. The card carries the diff, so the thing you are judging is in front of you when you judge it.

Every yes costs a context switch

A long run asks a lot. Each answer is a window switch out and back, and the way back is never quite where you left. Enter allows, Esc denies, and focus returns to the terminal on its own.

Nothing tells you what it has spent

Cost and context fill up silently until a run stops. The notch keeps both on screen, and can stop a session at a cap you set rather than after the fact.

rm -rf reads like every other line

In a scrolling terminal a destructive command looks exactly like a safe one. Dangerous commands get a different card, and can be put behind Touch ID.

When you should skip it

If you sit in the terminal while Claude works, run short tasks you watch end to end, or already run everything on auto-approve, the terminal is not costing you anything and this will not help. It earns its place when you leave the session running and go do something else.

How it works

Up and running in three steps

1

Install and run setup

Open the app and click through the one-click setup. It grants accessibility and input permissions, then wires ClaudeNotch into Claude Code's hooks.

2

Run Claude Code

Start a session in any terminal, exactly like you always do. No flags, no wrappers, nothing new to learn.

3

Respond in the notch

Prompts appear up top. Press Enter to allow, Esc to deny, and keep working without switching windows.

Install

Get set up in under two minutes

Works on notched MacBooks and ordinary Macs alike. On a Mac without a notch it draws a Dynamic-Island-style pill instead.

  1. 1

    Download ClaudeNotch.dmg

    Grab the latest release. The link always points to the newest build.

  2. 2

    Drag it to Applications

    Open the disk image and drag ClaudeNotch into your Applications folder.

  3. 3

    First-launch warning (one time)

    macOS blocks the first launch. Click Done, then open System Settings → Privacy & Security and click Open Anyway next to ClaudeNotch. Or install with Homebrew below to skip this entirely.

  4. 4

    Run the Setup window

    It walks you through Accessibility and Input Monitoring, then installs the Claude Code hooks. It backs up your ~/.claude/settings.json first.

  5. 5

    Start coding

    Launch a Claude Code session in your terminal. Prompts now appear in the notch.

Requirements

  • macOS 13 (Ventura) or later
  • Apple Silicon or Intel
  • Claude Code CLI installed
  • jq recommended (brew install jq) for the live activity line

Works with Claude Code in any terminal, including the one inside VS Code. The Claude Code VS Code extension panel does not fire hooks yet, so use the CLI there.

Updating later

One command fetches the new version, checks it against the published checksum, and swaps it in. Installed with Homebrew? Use brew upgrade --cask rawsun007/tap/claudenotch instead, and this will say so rather than working behind Homebrew's back.

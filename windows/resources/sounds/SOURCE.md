# Where these sounds come from

The 13 sounds here (Funk, Pop, Tink, Glass, Submarine, Hero, Blow, Bottle,
Frog, Morse, Ping, Purr, Sosumi) are from
[extratone/macOSsystemsounds](https://github.com/extratone/macOSsystemsounds),
commit `f3e8dcd8d2318d099ade479ad1b9778ce4e65cc7`, converted from AIFF to
16-bit WAV by `windows/tools/import_sounds.py`.

That repository is released under
[The Unlicense](https://github.com/extratone/macOSsystemsounds/blob/main/LICENSE.md),
a public-domain dedication, and its owner gave the ClaudeNotch project
owner permission to use them in the app (November 2026).

The repository describes them as macOS system sounds. If a rights holder
asks for them to be removed, delete these WAV files and run the old
generator from git history (`windows/tools/make_sounds.py`, removed in
0.45.2) to put original sounds back under the same names.
